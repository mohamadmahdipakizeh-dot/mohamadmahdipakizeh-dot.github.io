Project Overview

This project is a massage salon website designed and built using WordPress and Elementor. It helps visitors explore available services, review service information, and find contact details and booking inquiry options.

Features

- Responsive layout for mobile and tablet devices
- Massage service listings
- Service pricing and related information
- Image gallery
- Contact information and contact form
- Booking inquiry section
- Visual animations and interactions
- Customized page layouts and styling

Technologies

- WordPress
- Elementor
- HTML
- CSS
- JavaScript
- GitHub Pages for static deployment

My Contributions

- Designed and implemented nearly all website sections
- Prepared the main website content
- Selected and prepared images and visual assets
- Customized CSS styling
- Debugged code and refined page presentation
- Prepared and deployed the static website version
